This is a product website for Zayla, a luxury women's heels brand. It currently show five pruducts .It has three pages: Home, Products, and Contact.

I built it using HTML and CSS for structure and styling, and added JavaScript for interactivity: a welcome pop-up when the page loads, the current year shown automatically in the footer, a "Check Availability" button on each product, and a contact form with required field validation.
